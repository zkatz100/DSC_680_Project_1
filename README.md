# Predicting Susceptibility to ads.
In this code we train a KNN model and a Decision Tree to predict whether a customer will be more or less susceptible to ads based on varius demographic and shopping habit related features.
The data for this project comes from the Consumer Shopping Behavior & Buying Survey Dataset on Kaggle, which is distributed with a CC0 Universal Deed licence.


First of two final projects for the Data Science program at Bellevue University.
